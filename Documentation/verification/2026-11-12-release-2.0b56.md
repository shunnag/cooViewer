## リリースノートの判断

- 2.0b54 の 793 さんへの返答と既定キーの表は、2.0b55 では本文に残した。今回は 1 週間たったため、「前回までの主な変更」に 2.0b54・2.0b55 のリリースへのリンクを置く形にした。Sparkle の更新画面は最新版のノートだけを表示するため、2.0b53 以前から直接更新する利用者もリンクから辿れる。
- PR #79 はノートに載せなかった。修正前も、次の巻のスプールは前の巻の枠が空くまで `gate.acquire` で待つだけで、利用者に見える違いは無い(`NestedFolderSource.scheduleWindow` から追って確認)。
- Washi 1.27.0 の、著者スクリプトが作った合成イベントを実入力として扱わない変更は、cooViewer では `allowsScriptedContent` が既定の false のため当たらない。音声・動画の自動再生は 1.26.0 から既に利用者の操作を要したため、`allowsMediaAutoplay`(既定 false)の追加でも挙動は変わらない。どちらもノートに載せなかった。

## このリリースで配布する変更

- Washi 1.27.2: ZIP のエントリ名の検査(`..` や制御文字を含む名前を列挙しない。`./` と `/` で始まる名前は 1.27.2 で別名として読める)、census・キャッシュ・検索・表紙・朗読音声・scheme handler の資源上限。残る挙動の変更は、spine が 8,192 を超える本の総ページ数を実測しない、宣言画素数が 8,192 × 8,192 を超える表紙は合本のリフロー EPUB で題名表示になる、抽出本文が 1,000,000 文字を超える章は検索しない、512 MiB を超える朗読音声は再生しない、の 4 点。
- `KaitoKit-NOTICE.txt`(`../KaitoKit/NOTICE` の写し、Unicode License v3)と `Sparkle-LICENSE.txt`(Sparkle 2.10.1 配布物の `LICENSE` の写し)をアプリに同梱し、Credits.rtf に記載した。
