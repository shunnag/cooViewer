## 途中で起きたこと

- PR #77 の初回 CI で hosted macos-26 の `testPromotionMovesExistingBackgroundWaitersToInteractiveSpool` が失敗した。KaitoKit ではなく、固定回数の `Task.yield` で待つテストの問題。CPU 負荷下で初回に再現し、10 秒期限の時間基準へ変えた後は同じ負荷で 30 回すべて通った。同じ待ち方の 6 か所を直した。
- その失敗中に、マージを確認せず Release build へ進んだため、版が 2.0b54 のままの zip が一度できた。公開前に気づいて破棄した。以後の build は master の commit と版を確認してから始めた。

## このリリースで配布する変更(KaitoKit の測定、0.21.0 比)

- LZ4 の独立ブロックを並列に検証し、64 MiB で 2.2〜2.6 倍。
- LArc は LZS の画像が約 1.8 倍、lz5 の画像が約 7% 短縮。
- PPMd は文書の PPMd I が約 16% 短縮。
- RAR は RAR20 biglz が約 1.7 倍、RAR15 の文書・音声が約 15〜28% 短縮。
- CAB LZX は実 product.cab が約 6.4% 短縮。
