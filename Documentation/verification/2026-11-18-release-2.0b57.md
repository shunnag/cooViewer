## リリースノートの判断

- 新機能の説明を先頭に置き、制限(PDF・サムネイル・原寸表示パネルには適用しない、画素数の上限、細い線が点線状になる既知の問題)を同じ節にまとめた。
- H キーは、キー設定を編集していない利用者にだけメモリ内で補う(1.x と共有する defaults へは書かない)。編集済みの利用者は自分で割り当てる必要があるので、その旨を書いた。
- 速さの数値は「通常は 0.1 秒前後、1300 万画素級で M2 Pro 約 0.4 秒」に留めた(合成ページでの実測)。
- 「前回までの主な変更」は 2.0b56 と 2.0b55 へのリンクにした。

## このリリースで配布する変更

- 網かけの表示(設定キー `HalftoneDisplayMode` / `HalftoneDisplayStrength`、キー操作 55、既定は切)。対象・素通しの条件・失敗時の扱い・キャッシュの印は設計書 §5。
- PrintAppearanceKit.framework(`engineVersion` 1)。出力のバイトは OS の vDSP・libm と GPU に依存するため、機種や OS の版が違うと同じ入力でも出力が 1 階調の範囲で異なりうる(M2 Pro / macOS 27.2 と M4 Max / macOS 27.3 で確認)。
