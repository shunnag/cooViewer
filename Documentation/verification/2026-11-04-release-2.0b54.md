## このリリースで配布する変更

| 操作 | 旧既定 | 新既定 |
|---|---|---|
| 次の本 | Control+C / Control+↓ | Shift+C / Shift+↓ |
| 前の本 | Control+D / Control+↑ | Shift+D / Shift+↑ |
| 次のサブフォルダ | Control+Shift+C / Control+Shift+↓ | Control+Shift+C / Option+Shift+↓ |
| 前のサブフォルダ | Control+Shift+D / Control+Shift+↑ | Control+Shift+D / Option+Shift+↑ |

- Control+↑/↓ は Mission Control / アプリケーションウインドウ、Control+Shift+↑/↓ はその低速版(symbolic hotkey 34/35)に先に取られる。
- 2.0 の UI で未編集の保存済み KeyArray には、キー+修飾の組が空いている行だけを起動時にメモリ内で補う。旧 Control 行は残し、1.x と共有する defaults へは書き戻さない。
